# Documentation screenshots

These images are real renders of the installed GitHub+ panel in BB. Repositories,
people, items, rules, jobs, and security alerts are fictional demonstration data.

For capture, the browser session intercepted GitHub Extended RPC requests and
returned demo responses. It blocked unhandled plugin requests, including writes.
The screenshots include only the plugin workspace; personal BB threads and other
application surfaces are outside the capture area.

- `inbox.jpg`: issues, pull requests, a security alert, and a pending approval.
- `automations.jpg`: an issue-triggered custom action with approval enabled.
- `activity.jpg`: run history, captured review output, and audit context.

Refresh captures when the corresponding surface changes. Use the current BB
render and fictional data; do not edit real screenshots to replace private text.
